# 🤖 AI Job Recommendation System

An AI-based job recommendation system built using Python, Pandas, and Streamlit.

## 📌 Project Overview

This project recommends the most suitable jobs for a user based on their:

- Skills
- Education
- Experience
- Interests

The system compares the user's skills with job requirements and provides the **Top 5 Job Recommendations** along with a match percentage and missing skills.

## ✨ Features

- Enter multiple skills
- Select education qualification
- Enter years of experience
- Get Top 5 recommended jobs
- Display match percentage
- Show matched skills
- Show missing skills
- Simple and user-friendly Streamlit interface

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
